# 4. SCAMP: структура каталогов, конфигурация и запуск

Рекомендуется отделять исходные данные, конфигурационные файлы и результаты обработки. Примерная структура рабочего каталога:

```text
project/
├── data/
│   └── image.fits
├── config/
│   ├── sextractor/
│   │   ├── default.sex
│   │   └── default.param
│   └── scamp/
│       └── scamp.conf
└── output/
```

> ⚠️ **Внимание.** Все последующие команды будут выполняться из корня проекта.

## 4.1. Конфигурационный файл SCAMP

Конфигурационный файл Scamp (`scamp.conf`) создается следующим образом:

```bash
scamp -d > config/scamp.conf
```

## 4.2. Запуск SCAMP


```bash
scamp catalogs/image.cat -c config/scamp.conf
```


## 4.3. Собственное движение

Текущая версия Scamp не учитывает собственное движение звезды (по крайней мере авторам документации это сделать не удалось), поэтому рекомендуется учитывать собственное движение непосредственно во входном каталоге другими программными средствами.
