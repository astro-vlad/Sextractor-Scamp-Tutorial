SExtractor + SCAMP

Собираем последние версии из исходников — и прикручиваем астрометрию к вашим снимкам

Что тут будет:
  • 1. Зачем вообще эти два зверя
  • 2. SExtractor: конфиг, который не взорвётся
  • 3. Установка из исходников (Linux / macOS / Windows)
  • 4. SCAMP: настройка и запуск
  • 5. Собираем всё вместе

1. Зачем вообще эти два зверя

Если вы когда-нибудь пытались сложить несколько астрономических снимков в кучу и получали на выходе звёздную кашу вместо картинки — вы уже знаете, зачем нужна астрометрическая привязка. SExtractor находит на снимке звёзды и галактики и делает из них каталог. SCAMP берёт этот каталог, сравнивает его с внешним астрометрическим каталогом (2MASS, Gaia и т.д.) и вычисляет уточнённые координатные заголовки (WCS). После этого изображение можно спокойно складывать, и звёзды не будут размазываться в полосы.

Работают они в паре: SExtractor выдаёт каталог в специальном формате FITS_LDAC, SCAMP его читает и на выходе отдаёт .head-файл с обновлёнными WCS-ключами. Дальше этот заголовок можно скормить SWarp'у или чему угодно ещё.

2. SExtractor: конфиг, который не взорвётся

SExtractor управляется тремя файлами: основной конфиг (default.sex), список параметров каталога (default.param) и, если нужно, файл свёртки. Самый простой способ получить отправную точку — сгенерировать дефолтный конфиг командой sex -d (или sex -dd, если хочется увидеть вообще все параметры, включая те, что обычно скрыты).

Для связки со SCAMP критично, чтобы выходной каталог был именно FITS_LDAC. Вот минимальный набор в default.sex, которого обычно достаточно:

CATALOG_NAME     sources.cat
CATALOG_TYPE     FITS_LDAC
PARAMETERS_NAME  default.param

DETECT_THRESH   1.5
DETECT_MINAREA  5

BACK_SIZE       64
BACK_FILTERSIZE 3

DEBLEND_NTHRESH 32
DEBLEND_MINCONT 0.005

А в default.param нужно перечислить параметры, которые SCAMP ожидает увидеть. Без них он просто не поймёт, что вы от него хотите:

NUMBER
XWIN_IMAGE
YWIN_IMAGE
ERRAWIN_IMAGE
ERRBWIN_IMAGE
ERRTHETAWIN_IMAGE
FLUX_AUTO
FLUXERR_AUTO
FLAGS
FLAGS_WEIGHT
IMAFLAGS_ISO
FLUX_RADIUS
ELONGATION
SPREAD_MODEL
SPREADERR_MODEL

Запускается это всё предельно скучно: sex image.fits -c default.sex. На выходе получаете sources.cat, который уже готов к отправке в SCAMP.

3. Установка из исходников

Пакетные менеджеры — это, конечно, удобно, но там версии иногда отстают на годы. Если хочется свежак — придётся собирать. Ниже — по-человечески, для трёх систем.

Linux (Debian / Ubuntu)

Сначала ставим всё, что нужно для сборки. Без этого ./configure будет ругаться на отсутствующие библиотеки.

sudo apt update
sudo apt install build-essential autoconf automake libtool pkg-config \
                 libcfitsio-dev libfftw3-dev libatlas-base-dev libplplot-dev

Для SCAMP ещё пригодится libcurl4-openssl-dev (он нужен для скачивания справочных каталогов онлайн).

Дальше — клонируем и собираем SExtractor. Версию можно взять из релизов на GitHub.

git clone https://github.com/astromatic/sextractor.git
cd sextractor
./autogen.sh
./configure --prefix=/usr/local
make -j$(nproc)
sudo make install

Если ./autogen.sh вдруг скажет, что чего-то не хватает — перечитайте список пакетов выше, почти наверняка забыли libtool или pkg-config.

Теперь SCAMP. Он живёт в отдельном репозитории.

git clone https://github.com/astromatic/scamp.git
cd scamp
./autogen.sh
./configure --prefix=/usr/local
make -j$(nproc)
sudo make install

Проверяем: sex --version и scamp -v должны что-то внятное ответить.

Маленькая хитрость: если не хочется засорять систему, добавьте --prefix=$HOME/.local при конфигурации. Тогда sudo не понадобится, а бинарники окажутся в ~/.local/bin — главное, чтобы этот путь был в $PATH.

macOS

На маке проще всего поставить зависимости через Homebrew, а сами программы собрать из исходников. Так вы получите свежие версии и не будете зависеть от того, что там положили мейнтейнеры формулы.

brew install autoconf automake libtool cfitsio fftw openblas plplot

Дальше — стандартная песня autotools, как и на Linux:

git clone https://github.com/astromatic/sextractor.git
cd sextractor
./autogen.sh
./configure --prefix=/usr/local
make -j$(sysctl -n hw.ncpu)
sudo make install

И то же самое для SCAMP:

git clone https://github.com/astromatic/scamp.git
cd scamp
./autogen.sh
./configure --prefix=/usr/local
make -j$(sysctl -n hw.ncpu)
sudo make install
Про Apple Silicon: если вы на M1/M2/M3, Homebrew по умолчанию ставит библиотеки в /opt/homebrew. configure обычно сам это подхватывает, но если начнёт ругаться на cfitsio — добавьте флаги CPPFLAGS="-I/opt/homebrew/include" и LDFLAGS="-L/opt/homebrew/lib" перед вызовом ./configure.

Windows

Тут всё чуть печальнее. Нативно собрать это добро под Windows — та ещё лотерея. Официально разработчики пишут, что код должен компилироваться на любой POSIX-совместимой системе, и в качестве примера приводят Cygwin[reference:0]. На практике проще всего не мучиться, а поставить WSL (Windows Subsystem for Linux) и внутри него повторить инструкцию для Ubuntu. Это займёт минут десять, зато потом всё будет работать как часы.

Если WSL по каким-то причинам не вариант — можно попробовать Cygwin, но готовьтесь к приключениям с путями и зависимостями. Инструкция будет ровно та же, что для Linux, только вместо apt — установщик пакетов Cygwin, и ./configure может потребовать ручного указания путей к библиотекам.

# Внутри WSL (Ubuntu) — всё как на обычном Linux
sudo apt update
sudo apt install build-essential autoconf automake libtool pkg-config \
                 libcfitsio-dev libfftw3-dev libatlas-base-dev libplplot-dev

git clone https://github.com/astromatic/sextractor.git
cd sextractor && ./autogen.sh && ./configure && make -j$(nproc) && sudo make install

git clone https://github.com/astromatic/scamp.git
cd scamp && ./autogen.sh && ./configure && make -j$(nproc) && sudo make install
Честно: я пробовал собирать SCAMP нативно под Windows через MSYS2 — это возможно, но количество подводных камней на квадратный сантиметр зашкаливает. WSL экономит нервы. Если у вас Windows 10 или 11 — берите WSL, не думайте.

4. SCAMP: настройка и запуск

SCAMP читает каталоги FITS_LDAC от SExtractor версии 2.4.4 и выше. Настройки живут в конфиге, который можно передать флагом -c. Вот довольно типичный набор:

GROUP_RADIUS     1.0

ASTREF_CATALOG   2MASS
ASTREF_BAND      DEFAULT

MATCH            Y
PIXSCALE_MAXERR  1.2
POSANGLE_MAXERR  5.0
POSITION_MAXERR  1.0

SOLVE_ASTROM     Y
DISTORT_DEGREES  3
CENTROID_KEYS    XWIN_IMAGE,YWIN_IMAGE
CENTROIDERR_KEYS ERRAWIN_IMAGE,ERRBWIN_IMAGE,ERRTHETAWIN_IMAGE
PHOTFLUX_KEY     FLUX_AUTO
PHOTFLUXERR_KEY  FLUXERR_AUTO

MERGEDOUTCAT_TYPE  FITS_LDAC
MERGEDOUTCAT_NAME  scamp_merged.cat

Запуск выглядит так:

scamp sources.cat -c scamp.conf

Если каталогов много, их можно перечислить в файле (по одному на строку) и скормить SCAMP'у через @:

scamp @catalog_list.txt -c scamp.conf

На выходе появится .head-файл (или несколько, если изображений было много) с обновлёнными WCS-ключами. Их можно применить к исходным FITS-файлам через MissFITS или сразу скормить SWarp'у для сложения.

Если SCAMP ругается на справочный каталог: по умолчанию он лезет в USNO-B1. Если у вас нет интернета или каталог недоступен, укажите локальный файл: ASTREF_CATALOG FILE и ASTREFCAT_NAME /path/to/catalog. Для оффлайновой работы это самый надёжный путь.

5. Собираем всё вместе

Минимальный конвейер для одного снимка выглядит до смешного коротко:

# 1. Достаём каталог источников
sex image.fits -c default.sex -CATALOG_NAME image.cat

# 2. Считаем астрометрию
scamp image.cat -c scamp.conf

# 3. Применяем заголовки (пример с MissFITS)
missfits image.fits image.head

После этого в заголовке image.fits появятся уточнённые CRVAL1, CRVAL2, CD1_1 и остальная WCS-братия. Точность обычно получается на уровне десятых долей пикселя и лучше — для сложения более чем достаточно.

Если что-то пошло не так на этапе SCAMP — первым делом смотрите на FLAGS в каталоге SExtractor. Объекты с подозрительными флагами (слипшиеся, обрезанные краем, с битыми пикселями) лучше отфильтровать ещё до астрометрии, иначе они будут путать сопоставление.
