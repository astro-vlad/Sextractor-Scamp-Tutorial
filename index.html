1. Введение

SExtractor (Source Extractor) — программное обеспечение для обнаружения и измерения объектов на астрономических изображениях. Оно создаёт каталоги источников с координатами, потоками, формами и другой информацией[reference:0].

SCAMP (Software for Calibrating AstroMetry and Photometry) — программа, которая вычисляет параметры астрометрической проекции по каталогам источников, полученным из FITS-изображений, и записывает решение в формате WCS (World Coordinate System)[reference:1].

Совместное использование SExtractor и SCAMP позволяет автоматически привязать изображение к небесной системе координат: SExtractor находит звёзды и создаёт каталог в формате FITS_LDAC, а SCAMP сопоставляет этот каталог с внешним астрометрическим каталогом (например, 2MASS или Gaia) и вычисляет уточнённые WCS-заголовки[reference:2]. Эти заголовки затем можно использовать для stacking (например, в SWarp) или для дальнейшей фотометрии[reference:3].

2. Установка

2.1. SExtractor

Самый простой способ — установить бинарный пакет из репозитория вашего дистрибутива Linux[reference:4]:

# Debian / Ubuntu
sudo apt-get install sextractor

# Fedora
sudo dnf install sextractor

Если в вашем дистрибутиве пакета нет или нужна последняя версия, соберите SExtractor из исходников с GitHub[reference:5]:

unzip sextractor-<version>.zip
cd sextractor-<version>
./autogen.sh
./configure
make -j
sudo make install

Проверка установки:

sex --version

2.2. SCAMP

SCAMP также распространяется через пакетные менеджеры (например, apt-get install scamp или dnf install scamp). При сборке из исходников используются стандартные шаги ./configure && make && sudo make install. Официальная документация доступна на scamp.readthedocs.io.

3. SExtractor: извлечение каталога источников

3.1. Создание конфигурационных файлов

SExtractor управляется тремя основными файлами: конфигурационным (default.sex), списком параметров каталога (default.param) и, при необходимости, файлами свёртки и нейросети. Если конфигурационный файл не указан, программа ищет default.sex в текущем каталоге[reference:6]. Сгенерировать шаблон конфигурации можно командой:

sex -d > default.sex

Для более полного шаблона (с редко используемыми параметрами) используйте sex -dd > default.sex[reference:7].

3.2. Ключевые параметры конфигурации

Для совместимости с SCAMP критически важно установить тип выходного каталога в FITS_LDAC и включить нужные измерения[reference:8]. Ниже приведён минимально необходимый фрагмент default.sex:

CATALOG_NAME     sources.cat
CATALOG_TYPE     FITS_LDAC
PARAMETERS_NAME  default.param

# Порог обнаружения (в сигмах)
DETECT_THRESH   1.5
DETECT_MINAREA  5

# Фильтрация
FILTER_NAME      default.conv
DEBLEND_NTHRESH  32
DEBLEND_MINCONT  0.005

# Оценка фона
BACK_SIZE       64
BACK_FILTERSIZE 3

# Выходные параметры (для SCAMP)
# Должны быть включены в default.param

3.3. Файл параметров каталога (default.param)

SCAMP требует наличия в каталоге определённых измерений. В файле default.param каждый параметр указывается на отдельной строке[reference:9]. Минимальный набор, рекомендуемый документацией SCAMP[reference:10]:

NUMBER
XWIN_IMAGE
YWIN_IMAGE
ERRAWIN_IMAGE
ERRBWIN_IMAGE
ERRTHETAWIN_IMAGE
FLUX_AUTO
FLUXERR_AUTO
FLAGS
FLAGS_WEIGHT
IMAFLAGS_ISO
FLUX_RADIUS
ELONGATION
SPREAD_MODEL
SPREADERR_MODEL
Пояснение: XWIN_IMAGE и YWIN_IMAGE — взвешенные по гауссу центроиды; FLUX_AUTO — автоматическая (адаптивная) апертурная фотометрия; FLAGS помогает SCAMP отфильтровать дефектные или слившиеся объекты[reference:11].

3.4. Запуск SExtractor

sex image.fits -c default.sex

После выполнения будет создан файл sources.cat в формате FITS_LDAC, содержащий каталог источников и копию заголовка исходного изображения. Именно этот файл передаётся в SCAMP.

4. SCAMP: астрометрическое решение

4.1. Входные данные

SCAMP читает каталоги в формате FITS_LDAC, созданные SExtractor версии 2.4.4 или выше[reference:12]. Каталог должен содержать как минимум центроиды, их ошибки, потоки и ошибки потоков (см. раздел 3.3).

4.2. Конфигурационный файл SCAMP

SCAMP, как и SExtractor, использует конфигурационный файл. Если он не задан явно, параметры берутся по умолчанию. Для управления процессом создайте файл, например scamp.conf. Ключевые параметры[reference:13]:

# --- Группировка полей ---
GROUP_RADIUS     1.0          # Максимальное расстояние между группами (град)

# --- Справочный каталог ---
ASTREF_CATALOG   2MASS        # Может быть USNO-B1, Gaia (через FILE), 2MASS и др.
ASTREF_BAND      DEFAULT      # Фотометрическая полоса для звёзд сравнения

# --- Сопоставление (pattern matching) ---
MATCH            Y
MATCH_NMAX       0            # 0 = авто
PIXSCALE_MAXERR  1.2          # Максимальная ошибка масштаба
POSANGLE_MAXERR  5.0          # Максимальная ошибка позиционного угла (град)
POSITION_MAXERR  1.0          # Максимальная позиционная ошибка (угл. мин)

# --- Астрометрическое решение ---
SOLVE_ASTROM     Y
DISTORT_DEGREES  3            # Степень полинома дисторсии
CENTROID_KEYS    XWIN_IMAGE,YWIN_IMAGE
CENTROIDERR_KEYS ERRAWIN_IMAGE,ERRBWIN_IMAGE,ERRTHETAWIN_IMAGE
PHOTFLUX_KEY     FLUX_AUTO
PHOTFLUXERR_KEY  FLUXERR_AUTO

# --- Выходные каталоги ---
MERGEDOUTCAT_TYPE  FITS_LDAC
MERGEDOUTCAT_NAME  scamp_merged.cat
Важно: Если вы используете локальный файл справочного каталога, установите ASTREF_CATALOG FILE и укажите путь в ASTREFCAT_NAME[reference:14]. По умолчанию SCAMP обращается к USNO-B1[reference:15].

4.3. Запуск SCAMP

Синтаксис командной строки[reference:16]:

scamp source1.cat [source2.cat ...] -c scamp.conf

Если каталогов много, удобно передать их списком в файле (по одному имени на строку), указав этот файл с префиксом @[reference:17]:

scamp @catalog_list.txt -c scamp.conf

4.4. Выходные файлы

SCAMP создаёт:

  • .head — FITS-заголовки с обновлёнными WCS-ключами, которые можно применить к исходным изображениям (например, с помощью MissFITS или SWarp)[reference:18].
  • Объединённый каталог (если MERGEDOUTCAT_TYPE не NONE) — калиброванные координаты и величины, усреднённые по всем перекрывающимся наблюдениям[reference:19].
  • Диагностические файлы — полезны для проверки качества решения.

5. Полный конвейер: от изображения к WCS

Ниже приведена минимальная последовательность команд для обработки одного изображения.

# 1. Извлечение каталога источников
sex image.fits -c default.sex -CATALOG_NAME image.cat

# 2. Астрометрическая калибровка
scamp image.cat -c scamp.conf

# 3. Применение обновлённых заголовков (пример с MissFITS)
# missfits image.fits image.head

# Альтернативно: SCAMP можно сразу указать записать обновлённые заголовки
# и затем использовать SWarp для stacking

После успешной работы SCAMP в директории появятся файлы image.head (или аналогичные) и объединённый каталог. Заголовки .head содержат уточнённые ключевые слова WCS (CRVAL1, CRVAL2, CD1_1 и т.д.), которые обеспечивают астрометрическую привязку с точностью до десятых долей пикселя и лучше[reference:20].

6. Заключение

Связка SExtractor + SCAMP является стандартным инструментом в астрономических конвейерах обработки. SExtractor быстро и надёжно извлекает каталоги источников, а SCAMP использует их для вычисления астрометрического решения с учётом дисторсии оптики. Правильная настройка формата FITS_LDAC и набора параметров каталога — залог успешной работы SCAMP. Дополнительные примеры и тонкая настройка описаны в официальной документации обоих пакетов.
