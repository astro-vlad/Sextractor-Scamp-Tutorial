
### 4.2.1 Справочные каталоги

**`REF_SERVER`**  
Адрес сервера Vizier, с которого скачиваются справочные каталоги. По умолчанию `vizier.unistra.fr` (Страсбург, Франция). Если загрузка медленная, можно переключиться на географически близкое зеркало: `vizier.nao.ac.jp` (Япония), `vizier.cfa.harvard.edu` (США) и др. При изменении достаточно указать имя хоста.

**`ASTREF_CATALOG`**  
Выбор источника справочного каталога. Допустимые значения: `NONE` (без справочного каталога), `FILE` (локальный файл), а также коды каталогов: `2MASS`, `GAIA-DR3`, `USNO-B1`, `PANSTARRS-1` и т.д. `2MASS` подходит для ИК и большинства оптических изображений; `GAIA-DR3` — highest точность, но более новое покрытие; `USNO-B1` — высокая плотность, но посредственная точность. Выбирайте по диапазону наблюдений и площади: для широкополосной оптики обычно `2MASS` или `GAIA-DR3`, для глубоких полей в высоких галактических широтах — `USNO-B1` для плотности.

**`ASTREF_BAND`**  
Фотометрическая полоса справочного каталога, используемая для сопоставления. `DEFAULT` — SCAMP автоматически выбирает предустановленную полосу каталога; можно явно указать имя полосы, либо `BLUEST`/`REDDEST` для самой синей/самой красной полосы. Если фильтр наблюдений сильно отличается от предустановленной полосы каталога, ручное указание близкой полосы улучшает сопоставление.

**`ASTREFMAG_LIMITS`**  
Диапазон звёздных величин справочного каталога (формат: `нижний,верхний`). По умолчанию `-99.0,99.0` — без ограничений. Если в каталоге много насыщенных ярких или шумных слабых звёзд, диапазон можно сузить, например `12.0,18.0`.

**`SAVE_REFCATALOG`**  
Сохранять ли скачанный справочный каталог в формате FITS-LDAC (`Y`/`N`). Значение `Y` позволяет повторно использовать каталог при последующих запусках, избегая повторной загрузки.

**`REFOUT_CATPATH`**  
Каталог для сохранения справочных каталогов. Действует только при `SAVE_REFCATALOG = Y`.

### 4.2.2 Выходные каталоги

**`MERGEDOUTCAT_TYPE`**  
Формат объединённого выходного каталога. `NONE` — не выводить; `ASCII_HEAD` — ASCII с заголовком; `ASCII` — чистый ASCII; `FITS_LDAC` — рекомендуемый формат, компактный, с полной точностью, читается в TOPCAT и подобных инструментах. Для повседневной работы рекомендуется `FITS_LDAC`.

**`MERGEDOUTCAT_NAME`**  
Имя файла объединённого каталога, по умолчанию `merged.cat`.

**`FULLOUTCAT_TYPE`**  
Формат полного выходного каталога (содержит все прошедшие отбор одиночные детекции, каждая привязана к источнику объединённого каталога). Варианты те же. Используется, когда нужно проследить происхождение каждого детекции.

**`FULLOUTCAT_NAME`**  
Имя файла полного каталога, по умолчанию `full.cat`.

### 4.2.3 Сопоставление по шаблону

**`MATCH`**  
Включать ли сопоставление по шаблону (`Y`/`N`). SCAMP сопоставляет шаблоны источников между входными кадрами для предварительного определения относительного масштаба и поворота, затем выравнивает по справочному каталогу. Если входной WCS не идеально точен, следует оставить `Y`.

**`MATCH_NMAX`**  
Максимальное число детекций, участвующих в сопоставлении. `0` — автоматически. Обычно менять не нужно; если в кадре очень много источников и сопоставление идёт медленно, можно задать несколько сотен — тысячу.

**`PIXSCALE_MAXERR`**  
Максимально допустимая относительная ошибка масштаба пикселя. По умолчанию `1.2` — допускается отклонение масштаба в пределах 20%. Если масштаб во входном WCS очень неточен, можно ослабить до `1.5` или `2.0`.

**`POSANGLE_MAXERR`**  
Максимально допустимая ошибка позиционного угла (градусы). По умолчанию `5.0`. При больших отклонениях наведения WCS можно ослабить.

**`POSITION_MAXERR`**  
Максимально допустимая ошибка положения (угловые минуты). По умолчанию `1.0`. Если начальное отклонение WCS может превышать 1 угловую минуту, значение нужно увеличить.

**`MATCH_RESOL`**  
Разрешение сопоставления (угловые секунды). `0` — автоматически. Обычно задавать вручную не требуется.

**`MATCH_FLIPPED`**  
Разрешать ли сопоставление с перевёрнутыми осями (`Y`/`N`). Устанавливается в `Y`, если изображения могут быть зеркально отражены.

**`MOSAIC_TYPE`**  
Способ связи нескольких чипов/расширений в мозаичном изображении. `UNCHANGED` — сохранять исходные относительные WCS; `SAME_CRVAL` — предполагать общую точку наведения для всех чипов; `FIX_FOCALPLANE` — статистически корректировать геометрию фокальной плоскости. Для многоПЗС-камер с плиткой чипов обычно наиболее устойчив `FIX_FOCALPLANE`.

### 4.2.4 Кросс-идентификация

**`CROSSID_RADIUS`**  
Начальный радиус поиска при кросс-идентификации (угловые секунды). По умолчанию `2.0`. Если точность положений каталога низкая или остаточные ошибки WCS велики, можно увеличить до `3.0`–`5.0`; слишком большое значение может привести к ошибочным сопоставлениям.

### 4.2.5 Астрометрическое решение

**`SOLVE_ASTROM`**  
Вычислять ли астрометрическое решение (`Y`/`N`). При `N` выполняется только сопоставление и вывод, без подгонки модели дисторсии.

**`PROJECTION_TYPE`**  
Тип проекции выходного WCS. `SAME` — наследовать входную проекцию; `TAN` — принудительно тангенциальная (плоскость); `TPV` — представление TPV с членами дисторсии. Для современной обработки рекомендуется `TPV` или `SAME`.

**`ASTRINSTRU_KEY`**  
FITS-ключевые слова, определяющие контекст «астрометрического инструмента» (через запятую). Кадры в одном контексте инструмента совместно используют модель дисторсии. По умолчанию `FILTER,QRUNID` — разные фильтры или ID запуска считаются разными инструментами. Если дисторсия камеры в разных фильтрах пренебрежимо различается, можно оставить только `QRUNID`, чтобы уменьшить число степеней свободы.

**`STABILITY_TYPE`**  
Уровень группировки по стабильности дисторсии. `EXPOSURE` — каждый кадр независим; `PRE-DISTORTED` — входные данные уже с исправленной дисторсией; `INSTRUMENT` — группировка по `ASTRINSTRU_KEY`. Для обычных камер выбирайте `INSTRUMENT`; если дисторсия может меняться от экспозиции к экспозиции, выбирайте `EXPOSURE` (больше степеней свободы, нужно больше перекрывающихся кадров).

**`CENTROID_KEYS`**  
Имена параметров SExtractor для координат центроида. По умолчанию `XWIN_IMAGE,YWIN_IMAGE` (гауссово-взвешенный центроид) — точнее, чем `X_IMAGE,Y_IMAGE`.

**`CENTROIDERR_KEYS`**  
Имена параметров эллипса ошибки центроида. По умолчанию `ERRAWIN_IMAGE,ERRBWIN_IMAGE,ERRTHETAWIN_IMAGE`, в паре с `CENTROID_KEYS`.

**`DISTORT_KEYS`**  
Параметры или FITS-ключевые слова для отображения дисторсии. По умолчанию совпадают с `CENTROID_KEYS`. Если нужно моделировать по координатам фокальной плоскости (например, `DETX,DETY`), а не по пиксельным, можно указать FITS-ключевые слова (с префиксом-двоеточием).

**`DISTORT_GROUPS`**  
Принадлежность каждого ключа дисторсии к группе полинома. `1,1` означает, что оба ключа относятся к группе 1.

**`DISTORT_DEGREES`**  
Степень полинома дисторсии. По умолчанию `3`. Для широкоугольных камер обычно требуется 3-я степень; для малых полей можно снизить до `2`, чтобы избежать переобучения.

### 4.2.6 Фотометрическое решение

**`SOLVE_PHOTOM`**  
Вычислять ли фотометрическое решение (`Y`/`N`).

**`MAGZERO_OUT`**  
Нуль-пункт звёздных величин в выходном каталоге. По умолчанию `0.0` — вывод инструментальных величин; значение вроде `30.0` даёт величины, близкие к физическим (зависит от единиц входного потока).

**`MAGZERO_INTERR`**  
Априорная точность внутреннего нуль-пункта (звёздные величины). Используется для взвешивания.

**`MAGZERO_REFERR`**  
Априорная точность нуль-пункта справочного каталога (звёздные величины). Если фотометрия справочного каталога менее точна, значение можно увеличить, чтобы снизить его вес.

**`PHOTINSTRU_KEY`**  
FITS-ключевые слова, определяющие контекст «фотометрического инструмента». По умолчанию `FILTER` — разные фильтры считаются разными фотометрическими системами. Если все кадры в одном фильтре, можно указать `QRUNID`.

**`MAGZERO_KEY`**  
Имя ключевого слова в выходном FITS-заголовке для хранения нуль-пункта. По умолчанию `PHOT_C`.

**`EXPOTIME_KEY`**  
FITS-ключевое слово времени экспозиции (секунды). По умолчанию `EXPTIME`. Если в заголовке ключа нет, время экспозиции принимается равным 1.0.

**`AIRMASS_KEY`**  
FITS-ключевое слово воздушной массы. По умолчанию `AIRMASS`.

**`EXTINCT_KEY`**  
FITS-ключевое слово коэффициента экстинкции (зв. вел./воздушная масса). По умолчанию `PHOT_K`. Если отсутствует, экстинкция принимается равной 0.

**`PHOTOMFLAG_KEY`**  
FITS-ключевое слово флага фотометрии.

**`PHOTFLUX_KEY`**  
Имя параметра потока для фотометрии. По умолчанию `FLUX_AUTO` (автоматическая апертура SExtractor).

**`PHOTFLUXERR_KEY`**  
Имя параметра ошибки потока. По умолчанию `FLUXERR_AUTO`.

### 4.2.7 Отбор источников

**`SN_THRESHOLDS`**  
Пороги отношения сигнал/шум (формат: `низкий,высокий`). Детекции ниже низкого порога отбрасываются; выше высокого — образуют «высокоС/Ш выборку», используемую в некоторых статистиках. По умолчанию `10.0,100.0`. Если изображение слабое и источников мало, низкий порог можно снизить до `5.0`; но источники ниже 5 обычно не стоит включать в решение.

**`FWHM_THRESHOLDS`**  
Допустимый диапазон FWHM (пиксели, формат: `нижний,верхний`). По умолчанию `0.0,100.0` — без отбора. Сужение диапазона исключает космические лучи (слишком малые) и оптические блики/протяжённые источники (слишком большие). Для работы входной каталог должен содержать `FLUX_RADIUS` или `FWHM_IMAGE`.

**`ELLIPTICITY_MAX`**  
Максимальная эллиптичность. По умолчанию `0.5`. Детекции с большим значением (например, смазанные, смешанные двойные) исключаются. Если сама PSF заметно эллиптична, можно ослабить до `0.6`–`0.7`.

**`FLAGS_MASK`**  
Маска отбраковки по `FLAGS` SExtractor (шестнадцатеричная). По умолчанию `0x00f0`. Детекции с установленными битами исключаются. `0x00f0` отбрасывает насыщенные, обрезанные, проблемные при декомпозиции источники, сохраняя флаги переполнения и декомпозиции. Для очень чистого набора можно использовать `0x00fc` (также исключить переполнение и декомпозицию); если источников мало, можно ослабить до `0x0000` (не отбраковывать по flags).

### 4.2.8 Заголовки WCS

**`AHEADER_SUFFIX`**  
Суффикс внешнего заголовочного файла на входе. Для каталога `xxxx.cat` SCAMP ищет `xxxx.ahead` и перекрывает ключевые слова исходного заголовка изображения. Позволяет дополнить или исправить WCS без изменения исходного FITS.

**`HEADER_SUFFIX`**  
Суффикс выходного обновлённого заголовочного файла, по умолчанию `.head`. Эти файлы содержат WCS и фотометрические ключевые слова после решения и могут напрямую использоваться в SWarp.

### 4.2.9 Проверочные графики

**`CHECKPLOT_DEV`**  
Устройство/формат вывода проверочных графиков. `NULL` — не создавать; `PNG` — рекомендуется; `PDF` — для публикаций; `XWIN`/`TK` — интерактивный показ. Для пакетной обработки используйте `PNG`.

**`CHECKPLOT_TYPE`**  
Список типов создаваемых проверочных графиков (через запятую). Основные:
- `FGROUPS` — обзор группировки кадров
- `DISTORTION` — визуализация модели дисторсии
- `ASTR_INTERROR1D/2D` — внутренние астрометрические невязки
- `ASTR_REFERROR1D/2D` — невязки относительно справочного каталога
- `ASTR_CHI2` — хи-квадрат по последовательности кадров
- `PHOT_ERROR` — фотометрические невязки

Оставляйте только нужные: лишние замедляют работу и создают много файлов.

**`CHECKPLOT_NAME`**  
Имена выходных файлов для каждого проверочного графика (без расширения); порядок должен соответствовать `CHECKPLOT_TYPE`.

### 4.2.10 Прочее

**`VERBOSE_TYPE`**  
Уровень подробности вывода в терминал. `QUIET` — без вывода; `NORMAL` — обычная информация; `LOG` — журнал с отметками времени; `FULL` — отладочный уровень. Для production используйте `NORMAL`, для отладки — `FULL`.

**`WRITE_XML`**  
Выводить ли отчёт о решении в формате XML (`Y`/`N`). XML содержит метрики качества решения, сведения об использовании справочного каталога и т.п., удобен для автоматизированной проверки в конвейере.

**`XML_NAME`**  
Имя файла XML-отчёта, по умолчанию `scamp.xml`.

**`NTHREADS`**  
Число параллельных потоков. `0` — автоматически использовать все доступные ядра. Для ограничения ресурсов задайте конкретное число (например, `4`).
