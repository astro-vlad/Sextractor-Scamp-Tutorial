# Sextractor-Scamp-Tutorial

*Установка, настройка и отождествление источников на изображениях*

## 1. Введение

Документ описывает установку и совместное использование SExtractor и SCAMP для астрометрической калибровки изображений. SExtractor формирует каталог источников, SCAMP вычисляет уточнённые параметры WCS на основе этого каталога и справочных данных.
